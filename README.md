# CareMate

## 1. Overview of the Project

CareMate is a simple Python-based daily life management application. It helps users manage daily tasks, expenses, care reminders, and personal records through a menu based program.

## 2. Features

* Add, view, and complete tasks
* Set task priority
* Add and view expenses
* Calculate total expenses
* Add and complete care reminders
* Optional period tracker
* Record period start date and cycle length
* Simple dashboard showing project information

## 3. Technologies / Tools Used

* Python 3
* Visual Studio Code
* Git / GitHub

No external Python packages are required.

## 4. Installation and Running

1. Install Python 3.
2. Open the CareMate project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```text
python main.py
```

5. Follow the options shown in the main menu.

## 5. Testing

The project can be tested by:

* Adding and completing a task
* Adding expenses and checking the total
* Adding and completing a care reminder
* Enabling and disabling the Period Tracker
* Adding and viewing a period record
* Checking the dashboard
